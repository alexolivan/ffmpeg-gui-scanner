# ffmpeg-gui-scanner

A lightweight desktop utility to discover and connect to `ffmpeg-gui` appliances running across local broadcast networks.

## Features

- **Automatic LAN Discovery**: Detects active `ffmpeg-gui` nodes in real time using lightweight UDP broadcast beacons.
- **Node Information**: Displays host IP, HTTP/HTTPS ports, node alias, system version, and active stream status.
- **One-Click Access**: Quickly launches the appliance web dashboard in the default browser.
- **Cross-Platform**: Standalone executable for Linux, Windows, and macOS.
